專案概述
[請在此處插入專案架構圖或技術棧截圖]
  • 技術架構：Spring Framework 5.3 + Spring Security + Hibernate + Thymeleaf
  • 資料庫：MySQL 8.0
  • 開發語言：Java 11
  • 專案類型：Web 應用程式（WAR）
  • 功能模組：用戶管理、商品管理、購物車、訂單管理、後台管理
  • 安全機制：Spring Security 認證授權、BCrypt 密碼加密、角色權限控制
1. 首頁功能
[請在此處插入首頁截圖]
  • 展示熱門商品、最新商品、推薦商品
  • 商品分類導航
  • 用戶登入狀態顯示
  • 購物車商品數量顯示
  • 響應式設計，支援多種裝置瀏覽
2. 用戶認證系統
[請在此處插入登入/註冊頁面截圖]
  • 用戶註冊：帳號、Email、密碼驗證
  • 用戶登入：Spring Security 認證機制
  • 忘記密碼：Email 驗證與密碼重設功能
  • 密碼加密：BCrypt 加密儲存
  • 角色管理：ADMIN、USER 角色權限控制
3. 商品展示功能
[請在此處插入商品列表/詳情頁截圖]
  • 商品列表：網格/列表視圖展示
  • 商品搜尋：關鍵字搜尋商品名稱與描述
  • 分類篩選：依商品類型篩選
  • 商品詳情：完整商品資訊、圖片、庫存狀態
  • 價格排序：支援價格升序/降序排序
4. 購物車功能
[請在此處插入購物車頁面截圖]
  • 添加商品：從商品列表或詳情頁加入購物車
  • 數量管理：增加、減少、移除商品
  • 庫存檢查：即時檢查商品庫存狀態
  • 總金額計算：自動計算購物車總金額
  • 購物車持久化：資料庫儲存購物車內容
5. 訂單管理系統
[請在此處插入訂單列表/詳情頁截圖]
  • 結帳流程：填寫收件資訊、選擇付款方式
  • 訂單建立：從購物車轉換為訂單
  • 訂單查詢：用戶可查看自己的訂單歷史
  • 訂單詳情：完整的訂單資訊與商品明細
  • 訂單狀態：PENDING、PROCESSING、SHIPPED、DELIVERED、CANCELLED
  • 付款狀態：UNPAID、PAID、REFUNDED
6. 商品管理（後台）
[請在此處插入後台商品管理頁面截圖]
  • 商品 CRUD：新增、編輯、刪除商品
  • 商品資訊：名稱、描述、價格、庫存、分類
  • 商品狀態：上架/下架管理
  • 庫存管理：庫存數量與最低庫存閾值設定
  • 圖片上傳：支援商品圖片上傳（Google Cloud Storage）
7. 用戶管理（後台）
[請在此處插入後台用戶管理頁面截圖]
  • 用戶列表：查看所有註冊用戶
  • 用戶編輯：修改用戶資訊、角色、啟用狀態
  • 角色管理：ADMIN、USER 角色分配
  • 帳號啟用/停用：控制用戶帳號狀態
  • 用戶搜尋：依使用者名稱或 Email 搜尋
8. 客戶管理
[請在此處插入客戶管理頁面截圖]
  • 客戶資料：姓名、電話、地址等完整資訊
  • 客戶編輯：修改個人資料
  • 客戶列表：管理員可查看所有客戶
  • 客戶關聯：與 User 帳號一對一關聯
  • 訂單關聯：客戶與訂單的關聯管理
9. 訂單管理（後台）
[請在此處插入後台訂單管理頁面截圖]
  • 訂單列表：查看所有訂單
  • 訂單篩選：依狀態、付款狀態、關鍵字搜尋
  • 訂單詳情：完整的訂單資訊與收件地址
  • 狀態更新：管理員可更新訂單狀態
  • 付款狀態：管理付款狀態
  • 分頁顯示：支援大量訂單的分頁瀏覽
10. 後台儀表板
[請在此處插入後台儀表板截圖]

  • 訂單統計：待處理訂單、已付款訂單數量
  • 銷售統計：總銷售額計算
  • 快速入口：商品管理、訂單管理、用戶管理
  • 數據視覺化：關鍵指標一目了然
技術特色
[請在此處插入程式碼或架構圖截圖]
